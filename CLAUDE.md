## Project Overview

This is a **Gradle multi-module Java project** for learning and experimenting with **Apache Kafka pipelines**.

The repository demonstrates an end‑to‑end event streaming architecture:

Wikimedia SSE API  
→ Kafka Producer  
→ Kafka Topic  
→ Kafka Streams Processing  
→ Kafka Consumer  
→ OpenSearch Indexing

The project is also used as a **base for implementing Data Engineering exercises**.

---

## Environment

- Java version: **21**
- Build tool: **Gradle (wrapper)**
- Kafka client version: **3.3.1**
- Streams library: **Kafka Streams**
- Search engine: **OpenSearch**

Always build the project using the Gradle wrapper:

```
./gradlew build
```

```

## Architecture

Each module demonstrates a different stage in a Kafka data pipeline.

Modules are defined in `settings.gradle`.

### kafka-basics
Core Kafka producer/consumer patterns:
- simple producers
- callbacks
- message keys
- cooperative rebalancing
- manual assign/seek
- multi-threaded consumers

### kafka-producer-wikimedia
Streams real-time events from the **Wikimedia Recent Changes API** using SSE.

Output topic:

```
wikimedia.recentchange
```

### kafka-consumer-opensearch
Consumes Kafka messages and indexes them into **OpenSearch**.

Key features:
- manual offset commits
- bulk indexing
- idempotent writes

### kafka-streams-wikimedia
Kafka Streams analytics application performing aggregations such as:

- bot activity counts
- website edit counts
- event timeseries windows

Typical development workflow:

Example pipeline execution:

```

## Development Rules

When modifying this repository:

- **Do NOT change the Gradle multi-module structure**
- Prefer **adding new classes instead of modifying existing ones**
- Keep code inside the existing modules
- Follow the package convention:

```
io.conduktor.demos.kafka.*
```

- Do not introduce new languages or frameworks
- Use **Java only**
- Do not rename existing Kafka topics
- Avoid modifying existing Gradle build files unless necessary
